# FEM Unit Tests

FEM（2D トラス有限要素法ソルバ: `src/shared/Fem.luau`）の単体テストスイートです。

## 実行系の選定理由

本テストスイートの実行ランナーとして **[Lune](https://github.com/lune-org/lune)（固定バージョン: `0.11.1`）** を採用しています。

- **採用理由**:
  - Roblox / Luau エコシステムにおける標準的なスタンドアロン Luau ランタイムであり、ファイルを直接 `lune run <file>` で実行可能。
  - Luau の型アノテーションや最新シンタックスをネイティブにサポートしている。
  - プロセス制御（`@lune/process` による終了コード制御など）が容易であり、テストの合否に応じた非ゼロ終了をシンプルに実現できる。
  - CI（GitHub Actions）およびローカル環境で `cargo install lune --version 0.11.1 --locked` 等によりバージョン固定して同一挙動を担保しやすい。

## 実行方法

### 依存関係のセットアップ
Lune をインストールします（バージョン `0.11.1`）:

```bash
cargo install lune --version 0.11.1 --locked
```

### テスト実行
リポジトリルートから以下の 1 コマンドで実行します:

```bash
lune run tests/run.luau
```

全ケース成功時は終了コード 0、いずれかのケースが失敗した場合は非ゼロ（終了コード 1）で終了します。

## Color3 スタブの仕組み

`src/shared/Fem.luau` は内部の `stressToColor` 関数で Roblox のグローバルデータ型 `Color3` を参照しています。

Fem.luau 本体を Roblox 実行環境に依存しない純粋な Luau（Pure Luau）として保つため、`tests/run.luau` では `require("../src/shared/Fem")` を呼び出す前に最小限の `Color3` スタブをグローバル環境（`getfenv().Color3`）に注入しています。

- スタブで実装しているインターフェース:
  - `Color3.new(r, g, b)`
  - `Color3.fromRGB(r, g, b)`
  - `Lerp(goal, alpha)`: メソッド呼び出し（`c:Lerp(...)`）およびメンバー関数呼び出し（`c.Lerp(...)`）の双方に対応

これにより、テスト都合による Roblox 依存を `src/shared/Fem.luau` に持ち込むことなく、ヘッドレス環境で直接 require してテストできます。

## テストケース一覧

1. **単一棒（水平）引張**:
   - 節点 1 固定、節点 2 に引張荷重 $P$ を印加。
   - 変位 $\Delta = \frac{PL}{EA}$、応力 $\sigma = \frac{P}{A}$、軸力 $P$ が解析解と相対誤差 $10^{-6}$ 以内で一致することを検証。
2. **2 本トラス（三角）**:
   - 2 つのピン支持節点と頂点節点からなる対称三角トラスに鉛直荷重 $-P$ を印加。
   - 部材軸力（圧縮力）、頂点変位、および支持反力（水平反力釣合と鉛直反力和 $= P$）が手計算の解析解と一致することを検証。
3. **支持不足（メカニズム）**:
   - 剛体回転や支持不足による特異行列・機構（メカニズム）を検証。
   - 将来の堅牢化 Issue で `res.ok == false` が返る仕様に対応し、現在はゼロ除算や未捕捉例外でクラッシュしないことを検証。
4. **破壊判定（座屈 / 降伏）**:
   - 座屈・降伏判定機能が未実装の間はスキップ（`[SKIP]`）され、機能追加後に検証が実行される構造。
